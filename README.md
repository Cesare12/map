# 想去地图

一个以地图为首页的微信小程序。用户可以保存从抖音、小红书等地方看到的店铺，按分类与种草/拔草状态筛选，查看距离，记录到访，并唤起系统地图导航。分类可从统一图标库选择颜色和图形；顶部分类、地点编辑页与地图图钉自动使用同一套样式，图钉外壳用于区分种草和拔草。

图钉状态遵循 Apple 提醒事项的完成语义：描边图钉表示尚未完成的“种草”，实心图钉配勾表示已经完成的“拔草”；地图当前选中地点通过放大和地点卡片表达。

## 当前版本

V0 本地验证版已经包含：

- 地图首页和当前位置
- 微信地图地点搜索，以及底图未收录时直接在地图上选点
- 分类筛选、自定义分类，以及统一入口中的分类名称、颜色和图标修改
- 种草、拔草、再次种草的明确状态流转
- 地图标记和地点卡片按种草/拔草区分
- 重叠地点按缩放级别自动聚合成带数量的标记
- 统一的分类图钉、轻量筛选栏和互斥底部卡片
- 地图地点卡直接显示种草笔记
- 按直线距离排列的附近卡片
- 调起地图导航
- 本机持久化和 JSON 文本备份
- 定位拒绝、空数据和屏外地点提示

照片、云备份、微信登录、付费和日历提醒不在 V0 中。

## 打开项目

1. 安装并登录微信开发者工具。
2. 选择“导入项目”，目录选择本文件所在目录。
3. AppID 已配置为 `wx0fea2490b1be2ff3`。
4. 在微信公众平台选择“工具 → 信息查询”，申请 `wx.getLocation` 和 `wx.chooseLocation` 接口。
5. 开发期间可在开发者工具中暂时关闭“不校验合法域名”；本版本没有自有网络请求。

## 真机验收

至少用一台 iPhone 和一台安卓手机验证：首次拒绝定位、重新授权、选择同名分店、分类切换、种草转拔草、再次种草、外部导航、本地重启后数据仍在。

本项目不会使用 AppSecret。以后增加云备份时，AppSecret 和支付密钥只能保存在服务端。
