# 想去地图

一个以地图为首页的微信小程序。用户可以保存从抖音、小红书等地方看到的店铺，按美食、宠物、洗车等类别筛选，查看距离、调起导航，并记录到访状态。

## 当前版本

V0 本地验证版已经包含：

- 地图首页和当前位置
- 微信地图选点
- 分类筛选和自定义分类
- 种草、拔草、再次种草的明确状态流转
- 地图标记和地点卡片按种草/拔草区分
- 按直线距离排列的附近卡片
- 调起地图导航
- 本机持久化和 JSON 文本备份
- 定位拒绝、空数据和屏外地点提示

照片、云备份、微信登录、付费和日历提醒不在 V0 中。

## 打开项目

1. 安装并登录微信开发者工具。
2. 选择“导入项目”，目录选择本文件所在目录。
3. AppID 已配置为 `wx0fea2490b1be2ff3`。
4. 在微信公众平台选择“工具 → 信息查询”，申请 `wx.getLocation` 和 `wx.chooseLocation` 接口。
5. 开发期间可在开发者工具中暂时关闭“不校验合法域名”；本版本没有自有网络请求。

## 真机验收

至少用一台 iPhone 和一台安卓手机验证：首次拒绝定位、重新授权、选择同名分店、分类切换、种草转拔草、再次种草、外部导航、本地重启后数据仍在。

本项目不会使用 AppSecret。以后增加云备份时，AppSecret 和支付密钥只能保存在服务端。
